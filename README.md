# Social Media Post Scheduler

Every site that provides this functionality seems to charge an absurd amount of money even though all the platforms expose a relatively simple to use API.
This project will provide the basic functionality to schedule social media posts or post to multiple accounts in one operation through a web-app you may host yourself. 
It should also display whatever information about the configured accounts is available from the various service endpoints.
